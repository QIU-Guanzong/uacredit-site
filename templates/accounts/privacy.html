此客戶中心目前只供重建預覽及測試。正式公開服務前，將由環聯確認正式的個人資料收集聲明、查閱更正聯絡方式及保留安排。

開立帳戶

帳戶使用你提供的手機或電郵作登入識別，並保存經單向處理的密碼摘要、帳戶狀態及操作紀錄，以提供登入、驗證及保安功能。不會保存可還原的密碼。

手機與電郵驗證

手機驗證使用 Twilio Verify 及 WhatsApp；電郵驗證使用 Twilio Verify 及 SendGrid。{% if not email_ready or not whatsapp_ready %}{{ '電郵及 WhatsApp' if not email_ready and not whatsapp_ready else ('電郵' if not email_ready else 'WhatsApp') }}驗證尚未開通。{% endif %}發送驗證碼時，所選聯絡資料會交予相關服務商處理。

香港身份證驗證

{% if kyc_ready %}{% if kyc_sandbox %}目前使用身份驗證服務商的測試環境，測試結果不代表正式實名認證。{% endif %}你可選擇前往 Sumsub 完成身份驗證，其頁面會說明所需資料。{% else %}身份驗證服務尚未開通；開通前須由環聯確認服務商、適用文件、資料用途、保留時間及私隱安排。{% endif %}本網站不接收身份證號碼、證件圖片或自拍，只保存驗證狀態及服務參考，不下載證件圖片。

誰可管理帳戶

獲授權的網站管理員可查看帳戶聯絡資料、驗證狀態及啟用狀態。帳戶資料獨立保存於環聯網站，不會供赤兔產品讀取或使用。

刪除帳戶

你可在客戶中心選擇「刪除帳戶」，輸入目前密碼並確認後，刪除本網站保存的相關帳戶資料。刪除後原有登入會失效，仍可直接瀏覽網站。查看刪除步驟與資料範圍，毋須登入。

查詢

如有帳戶或資料處理問題，請經環聯聯絡頁查詢。本說明只適用於這個客戶中心預覽；不取代正式貸款申請的資料收集聲明。
